# Support

zapVM is currently a developer preview. See `docs/support-matrix.md` before
using it for untrusted workloads.

For usage questions and reproducible bugs, open a GitHub issue with:

- `zapvm version` output;
- host OS, version, architecture, and hypervisor details;
- the command that failed, with secrets removed;
- `zapvm doctor` output;
- a default-redacted `zapvm diagnose` file when relevant.

Use the private process in `SECURITY.md` for vulnerabilities. Do not post tokens,
signing material, private paths, repository contents, VM state disks, or raw
console logs containing sensitive data.

The project does not currently provide a production SLA. Hardware combinations
not listed as accepted in the support matrix are best-effort community targets.
