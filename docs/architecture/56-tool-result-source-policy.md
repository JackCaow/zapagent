# 56. Host 工具结果来源策略

状态：SDK、Headless 与评测适配器的显式选项已实施；普通 CLI/TUI 和未配置此选项的历史 cohort 保持原行为。

## 边界与接线

`createResultSourceGuard()` 接受 Host 提供的 version 1 JSON：指定工具名、带稳定 ID 的 URL 子串排除项，以及有界扫描字符数。策略只做不区分大小写的字面比较，不运行用户正则。SDK 中没有题目名、题库 URL、答案或解题步骤，也没有默认排除项。

`ToolExecutorOptions.resultGuard` 在 Broker 返回后、普通后处理前检查结果，并在后处理/部分观察追加后再次检查最终结果。初次检查拒绝时直接返回，不再调用普通后处理或追加部分观察；后处理不能恢复已扣留内容。命中时扣留整个结果正文、原错误、multimodal 内容和工具 meta，返回通用来源范围说明。实际进程/执行回执保留；不把已经执行的命令改写成未执行，也不撤销工具副作用。自定义 guard 异常时不输出其异常正文。

最终检查位于 `content_final`、会话历史、Runtime 事件及 provider 消息投影之前。原始被扣留正文不进入这些通道；审计仅保留策略摘要、命中规则 ID、已检查正文摘要和 decision/reason。执行器所有 clone 与子 Agent 装配继承同一 guard。SDK 显式采用此选项不改变工具授权、后台清理、运行预算、自然结束或验收语义。

## Headless 与评测

`--result-source-policy <path>` 在模型调用之前读取最多 64 KiB 的常规 JSON 文件，拒绝末级符号链接和无效 schema，失败即参数错误退出。加载后采用内存快照；磁盘文件后续变化不改变本次策略。每个被指定工具的结果回执绑定实际加载字节的 SHA-256；策略值及排除 URL 不加入模型提示。

Harbor 适配器可显式传入 `result_source_policy_path`。setup 检查二进制接口支持，上传策略快照并收紧权限；不支持时不启动模型。run 检查父/子指定工具的每个结果是否携带匹配文件摘要的回执；缺失或不匹配保留运行事实并停止评分。被扣留的结果不等于 Agent 已消费参考材料，不能仅因一次拦截就宣布运行污染。

`evals/terminal_bench/independent-source-policy.json` 是评测 Host 的通用示例，仅排除整个 benchmark 语料的 URL 标记，不含单题名称。它不自动改写已经冻结的任务、二进制、配置、分数或重试策略。

## 覆盖范围与验收

这是已配置工具的字面 URL 文本结果策略，不是网络隔离。检查输入参数、正文、错误及文本块中的 URL；两次 percent 解码覆盖常见编码形式。超过有界检查范围时扣留结果并标记 scan_limit。图片中的来源、跳转后隐藏的地址、无品牌镜像、未配置的 MCP/进程/文件通道及编码程序仍需独立审查。工具可能已产生文件或网络副作用，结果扣留不证明这些副作用不存在。

不能把策略配置成功、一次 allowed 回执或事后扫描无命中称作 clean-source 证明。仍需保留轨迹、检查实际验证器与产物，区分执行结果、官方 reward 和独立性资格。已消费参考材料的原结果保留原分并标为不合格，不能靠补写策略恢复独立性或混入重试赢家。

验收覆盖 native stream、nonstreaming、XML、标准/concise、自定义提示、真实子装配、clone、后处理异常和失败时的部分观察。真实 CLI 对照使用受控本地文件工具与模型接口，验证默认原行为及显式策略下的模型消息/持久记录边界；SDK 的网络工具样本独立覆盖来源结果。现有 HTTP 私网/SSRF 防护保持原状，测试不通过放宽该边界连接回环站点。
